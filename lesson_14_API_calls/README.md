# Lesson 14 - API Calls in JavaScript

## Description

In this lesson, students learn how to work with APIs using `fetch` and `async/await`.
They will send `GET`, `POST`, `PUT`, and `DELETE` requests to a local JSON server,
read response data, and understand basic CRUD flow.

## Topics

- What an API is
- HTTP methods: `GET`, `POST`, `PUT`, `DELETE`
- `fetch()` basics
- `async` and `await`
- Parsing JSON with `response.json()`
- Sending request headers and body
- Basic CRUD workflow with users
- Working with `json-server`
