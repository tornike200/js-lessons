# Lesson 14 - In-Class Tasks: API Calls in JavaScript

Complete all 20 tasks in class. Use `console.log()` for outputs.

---

1. Start `json-server` with `db.json`.

---

2. Write `getUsers()` and print all users.

---

3. Print only the total number of users.

---

4. Write `getUserById(id)` and print user with id `1`.

---

5. Handle a missing user id and print a clear message.

---

6. Create a `newUser` object and send a `POST` request.

---

7. After creating, call `getUsers()` again and print updated list.

---

8. Write `updateUser(id, user)` with `PUT`.

---

9. Update one user's `userName` and `email`.

---

10. Confirm update by fetching the same user again.

---

11. Write `deleteUser(id)`.

---

12. Delete one user and print response.

---

13. Fetch all users again and verify deletion.

---

14. Add `try/catch` to `getUsers()`.

---

15. Print custom error message if request fails.

---

16. Create function `createAndReload(user)`:
    - create user
    - then reload all users

---

17. Create function `updateAndReload(id, user)`:
    - update user
    - then reload all users

---

18. Create function `deleteAndReload(id)`:
    - delete user
    - then reload all users

---

19. Add `API_URL` constant and reuse it in all requests.

---

20. Build a full CRUD demo sequence in comments that you can run step by step.
