# Lesson 18 - Homework: JavaScript Review

Complete all 20 tasks at home. These are slightly harder than in-class tasks.

---

1. Create an array of mixed values and print each value with its type.

---

2. Write a function `isTruthy(value)` that returns `true` or `false` based on JavaScript truthiness.

---

3. Create a loop that prints only even numbers from 1 to 30.

---

4. Write a function `formatUser(name, age)` that returns a formatted string.

---

5. Create an array of numbers and return a new sorted copy (ascending) without mutating the original.

---

6. Use `map()` on an array of names to produce objects like `{ name: "Ana", length: 3 }`.

---

7. Use `filter()` and `reduce()` together to sum only numbers greater than 10.

---

8. Create an object `course` with nested object `teacher` and print teacher email.

---

9. Loop over object keys and values using `for...in`.

---

10. Build a function `toggleStatus(item)` that returns a copied object with reversed `done` boolean.

---

11. In DOM, create a button that adds a random number to a list each click.

---

12. Add a second button that clears the list and resets counters.

---

13. Add a form with one input and prevent page reload on submit.

---

14. Validate form input length (`>= 3`) before adding data to list.

---

15. Use async/await to fetch todos from:
    `https://jsonplaceholder.typicode.com/todos?_limit=5`
    Render todo titles in DOM.

---

16. Show a loading message before fetch and hide it after data loads.

---

17. Add error UI message if fetch fails.

---

18. Save rendered todos into localStorage as JSON.

---

19. On page load, read todos from localStorage and render them.

---

20. **Mini Project - Task Tracker Review App**

Requirements:

- Add task
- Delete task
- Toggle completed state
- Filter all/completed/pending
- Persist data in localStorage
- Show total tasks and completed tasks counters
