# Lesson 18 - JavaScript Review (Beginner)

## Description

This lesson reviews the most important JavaScript topics from fundamentals to practical usage.
Students will revisit syntax, logic, data structures, DOM, and async code in one structured session.

## Topics Covered

- Variables, data types, and scope
- Operators, conditionals, and truthy/falsy values
- Loops (`for`, `while`, `for...of`)
- Functions (declaration, expression, arrow)
- Arrays and common methods (`push`, `pop`, `map`, `filter`, `reduce`)
- Objects and object methods
- DOM selection and updates
- Events and basic UI interaction
- Asynchronous JavaScript (`Promise`, `async/await`)
- Fetch API basics and error handling
- Local storage basics

## Why This Lesson Matters

In real projects, developers constantly combine these concepts together.
This review helps students connect separate lessons into one workflow.

## Mini Project

Build a "Task Tracker Review App" that can:

- Add tasks
- Mark task as done
- Filter completed tasks
- Save and load tasks from localStorage
