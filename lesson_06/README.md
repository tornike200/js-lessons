# Lesson 6 - DOM Manipulation Intro

## Description

In this lesson, you learn the basics of DOM (Document Object Model) manipulation in JavaScript. You will select elements from HTML, read and change their content, style them with JavaScript, and react to user actions with events.

## Topics

- What is the DOM
- Selecting elements with `querySelector` and `querySelectorAll`
- Difference between selecting by tag, id, and class
- Reading and changing text with `textContent`
- Changing CSS styles from JavaScript
- Looping through multiple elements with `forEach`
- Handling click events with `addEventListener`
- Simple state toggle logic with a boolean variable
