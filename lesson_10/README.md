# Lesson 10 - DOM Manipulation and Events

## Description

In this lesson, students learn how to work with the DOM (Document Object Model).
They will select elements, change content and styles, add and remove classes,
and respond to user actions with events.

## Topics

- What window and document are
- Selecting elements (`getElementById`, `querySelector`, `querySelectorAll`)
- Changing text (`textContent`, `innerHTML`)
- Changing styles with JavaScript
- Adding and removing classes (`classList.add`, `classList.remove`, `classList.toggle`)
- Event listeners (`click`)
- Simple show/hide UI behavior
