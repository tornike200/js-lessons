# Lesson 9 - Objects in JavaScript

## Description

In this lesson, students learn how to store related data inside JavaScript objects.
They will create objects, read and update properties, add and delete keys, work with nested objects,
and loop through object properties.

## Topics

- What an object is
- Key-value pairs
- Dot notation and bracket notation
- Updating existing properties
- Adding new properties
- Deleting properties with `delete`
- Nested objects
- Object methods
- `this` inside an object method
- Looping through an object with `for...in`
