# Lesson 7 - Arrays Basics

## Description

In this lesson, students learn how to work with arrays in JavaScript.
They will create arrays, access values by index, update items, and use common array methods to add, remove, copy, and transform data.

## Topics

- What an array is
- Array indexing (starts at 0)
- Reading and updating values
- `length` property
- `push`, `pop`, `shift`, `unshift`
- `reverse` and `sort`
- `slice` vs `splice`
- `split` and `join`
