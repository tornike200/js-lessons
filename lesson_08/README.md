# Lesson 8 - Loops in JavaScript

## Description

In this lesson, students learn how to repeat code using loops in JavaScript.
They will use `for`, `while`, and `do...while` to run code a set number of times or until a condition changes,
and `for...of` to iterate over arrays, and `for...in` to iterate over object keys.

## Topics

- `for` loop — syntax, counter, condition, step
- Looping through arrays with `for`
- `while` loop — condition-based repetition
- `do...while` loop — runs at least once
- `for...of` — loop over array values
- `for...in` — loop over object keys
- `break` and `continue`
